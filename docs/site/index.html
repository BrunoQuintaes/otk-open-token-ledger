# Health check

Architecture

OTK zk-Metering uses a Dual Receipt Model: full-fidelity RawReceipt for off-chain storage and minimal ZKReceipt for on-chain Groth16 proof verification. Cost Units (CU) normalize provider-specific token counts into a deterministic, bigint-based metering unit compatible with ZK circuits.

The system runs on an IBFT 2.0 Besu network (4 validators), with Solidity contracts for receipt registry and ZK verifier (Groth16, MPC ceremony with 5 contributors).
