# Glossário dos códigos internos nos comentários / Glossary of internal codes in comments

Os comentários do código citam códigos como H1, D1–D8, RV30-02 ou C157. São identificadores do processo de desenvolvimento e de revisão que produziu a versão avaliada: runs, ciclos de coordenação, achados de revisão, portas e documentos de projeto.
Esses comentários foram mantidos como estavam, para preservar a rastreabilidade entre o código e os registros desse processo; esta tabela explica o que cada família de códigos quer dizer.
Quando o repositório não registra o sentido de um código, a tabela diz isso em vez de adivinhar; os caminhos na última coluna são exemplos, não a lista completa.

The code comments cite codes such as H1, D1–D8, RV30-02 or C157. They are identifiers of the development and review process that produced the evaluated version: runs, coordination cycles, review findings, gates and design documents.
These comments were kept verbatim to preserve traceability between the code and the records of that process; this table explains what each family of codes means.
When the repository does not record the meaning of a code, the table says so instead of guessing; the paths in the last column are examples, not the full list.
